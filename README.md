# amr-engineering-portfolio
A production-grade personal engineering platform designed to showcase architecture, technical expertise, engineering principles, and professional experience as a Senior .NET Engineer.

This project is not a simple portfolio template.  
It is being engineered as a scalable, modern full-stack platform with enterprise-inspired architecture and clean development practices.

---

# Tech Stack

## Frontend
- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

## Backend
- ASP.NET Core Web API
- Clean Architecture
- CQRS Pattern
- MediatR
- FluentValidation
- JWT Authentication
- Serilog

## Infrastructure & DevOps
- Docker
- Docker Compose
- GitHub Actions
- CI/CD Ready

---

# Project Goals
- Build a production-quality engineering portfolio
- Demonstrate scalable architecture patterns
- Showcase backend and frontend engineering skills
- Implement enterprise-level development practices
- Prepare a future-ready platform for expansion and AI integration
