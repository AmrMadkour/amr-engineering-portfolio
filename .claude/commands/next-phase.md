# Next Phase Readiness Check (No Generation)

## Objective

Determine if the next phase is ready to be generated AND clearly explain what will be built.

---

## Required output

### 1. Current State
Summarize what is already implemented and stable.

### 2. Next Phase (What WILL be built)
Explain clearly:
- what features will be implemented
- what files/modules will be created or changed
- what architecture changes (if any)
- what dependencies or integrations will be used

### 3. Readiness Check
State clearly:
- READY or NOT READY
- and why

---

## Strict rules

- DO NOT generate any code
- DO NOT start implementation
- DO NOT suggest execution options
- DO NOT ask for confirmation menus
- DO NOT proceed beyond analysis
- DO NOT assume missing details

---

## Output must end here

Stop after:
- explanation
- readiness status
